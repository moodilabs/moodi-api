== 회원 관리

조회는 `OPERATOR`, 정지·강제 탈퇴는 `SUPER`입니다.

상태는 DB 상태에 "탈퇴"를 더한 4가지입니다.

|===
| 상태 | 의미

| `PENDING` | 온보딩 중 (프로필·약관 미완료)
| `ACTIVE` | 가입 완료
| `SUSPENDED` | 어드민 정지. 로그인·토큰 재발급이 막힘 (`MEMBER_SUSPENDED` 403)
| `WITHDRAWN` | 탈퇴. 개인정보는 비워져 있고 활동 수만 남음
|===

=== 정지 / 해제 (SUPER)

정지하면 리프레시 토큰이 지워져 재발급이 막힙니다. 이미 발급된 액세스 토큰은 30분 내 만료됩니다.
가입 완료(`ACTIVE`) 회원만 정지할 수 있고, `SUSPENDED` 회원만 해제할 수 있습니다.

==== 에러

|===
| 코드 | HTTP | 설명

| `MEMBER_NOT_FOUND` | 404 | 회원 없음 또는 탈퇴 회원
| `INVALID_REQUEST` | 400 | 상태 전이 불가 (온보딩 중 정지, 정지 아닌 회원 해제) 또는 사유 누락
|===
