== 인증 (Auth)

provider가 발급한 `id_token`을 백엔드가 JWKS로 검증한 뒤 자체 JWT(access·refresh)를 발급합니다.

==== 에러

|===
| 코드 | HTTP | 설명

| `OAUTH_VERIFICATION_FAILED` | 401 | id_token 검증 실패
| `DUPLICATE_EMAIL` | 409 | 다른 소셜 계정으로 이미 가입된 이메일
| `MEMBER_SUSPENDED` | 403 | 어드민에 의해 정지된 계정. 고객센터 안내 화면으로 분기
|===

==== 에러

|===
| 코드 | HTTP | 설명

| `INVALID_REFRESH_TOKEN` | 401 | 만료·폐기·위조된 refresh 토큰. 재로그인
| `MEMBER_SUSPENDED` | 403 | 정지된 계정. 재로그인해도 같은 에러
|===
