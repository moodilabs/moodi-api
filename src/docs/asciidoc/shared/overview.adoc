== Overview

=== 인증

모든 인증이 필요한 API는 요청 헤더에 Bearer 토큰을 포함해야 합니다.

[source,http]
----
Authorization: Bearer {accessToken}
----

토큰이 없거나 유효하지 않은 경우 401 응답을 반환합니다.
토큰이 만료된 경우 `/api/v1/auth/reissue` 를 통해 재발급 받아야 합니다.

==== 잘못된 형식의 요청

파라미터 타입 불일치, 필수 파라미터 누락, 본문 파싱 실패, 없는 경로, 허용되지 않은 메서드는
아래 코드로 내려갑니다. **서버 오류(500)와 구분해서 처리하세요** — 클라이언트가 고칠 수 있는 요청입니다.

|===
| 코드 | HTTP | 설명

| `INVALID_REQUEST` | 400 | 파라미터 타입 불일치 · 필수 파라미터 누락 · 본문 파싱 실패
| `NOT_FOUND` | 404 | 존재하지 않는 경로
| `METHOD_NOT_ALLOWED` | 405 | 해당 경로가 지원하지 않는 HTTP 메서드
|===
