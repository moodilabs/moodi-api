== 운영 콘텐츠 관리

모든 변경 API는 관리자 인증이 필요하며 OPERATOR와 SUPER가 사용할 수 있습니다.
노출 순서는 `sortOrder ASC, id ASC`입니다. `PUT /order`는 숨김 항목을 포함한 전체 ID를 원하는 순서로 받습니다.
누락·중복·알 수 없는 ID는 `INVALID_REQUEST` (400), 존재하지 않는 단건은 `RESOURCE_NOT_FOUND` (404)입니다.

=== 추천 루트

제목(100자), 대표 이미지 HTTP(S) URL(2,000자), 지역(100자), 노출 여부, 순서, 스팟 목록을 관리합니다. 일차(day)는 1~5, 일차별 순서(sequence)는 1~6이며 각각 1부터 연속이어야 합니다. 루트 내 중복 스팟은 허용하지 않습니다. 스팟은 PUBLISHED 상태여야 합니다. 회원 루트와 별도로 보관하며 회원 탈퇴에 영향을 받지 않습니다.

=== 추천 지역

level(REGION/DISTRICT/NEIGHBORHOOD), region, district, neighborhood는 아래 자동완성 결과를 그대로 사용합니다. label은 표시 이름(200자), sortOrder는 0 이상입니다. 자동완성 원장에 없는 지역은 등록할 수 없습니다. 인기 검색 통계와 별도로 운영자가 선정한 추천 지역입니다.

==== 지역 자동완성

앱의 `/api/v1/picks/areas`와 같은 후보(스팟이 실제로 있는 지역만)를 관리자 토큰으로 조회합니다. 키워드가 2자 미만이면 빈 목록입니다.

=== 사전조사 이미지

mood는 MoodTag enum 값, spotId는 대표 스팟 ID, imageUrl은 해당 스팟에 등록된 이미지 URL입니다. `/api/admin/spots/{id}`의 images에서 URL을 선택합니다. 다른 스팟의 이미지나 임의 URL은 허용하지 않습니다. sortOrder는 0 이상입니다. 삭제는 사전조사 연결만 지우며 원본 스팟 이미지는 지우지 않습니다.
