관리자 프론트(`admin.moodi.kr`)가 호출하는 API입니다. 외부에 배포하지 않습니다.

== 인증

모든 관리자 API는 `/api/admin/**` 아래에 있으며 로그인·재발급을 제외하고 `Authorization: Bearer {adminAccessToken}` 헤더가 필요합니다.
회원용 액세스 토큰으로는 호출할 수 없습니다(`UNAUTHORIZED` 401).

|===
| 권한 | 범위

| `OPERATOR` | 관리자 계정 관리를 제외한 모든 기능
| `SUPER` | 전체 + 관리자 계정 관리
|===

권한이 부족하면 `ADMIN_FORBIDDEN` 403입니다. 로그인 5회 실패 시 15분 잠깁니다(`ADMIN_ACCOUNT_LOCKED` 423).

CORS는 `admin.moodi.kr` 오리진에만 열려 있으며 쿠키는 쓰지 않습니다 — 토큰은 Authorization 헤더로만 보냅니다.

|===

== 관리자 계정 (SUPER)

최초 계정은 배포 환경변수 `ADMIN_BOOTSTRAP_LOGIN_ID` / `ADMIN_BOOTSTRAP_PASSWORD`로 기동 시 한 번 생성됩니다.
이후 계정은 여기서 추가합니다. 자기 자신의 상태·권한은 바꿀 수 없습니다.

새 계정은 항상 **초기 비밀번호 상태**(`passwordChangeRequired = true`)로 만들어집니다. 발급받은 관리자가 첫 로그인 후
본인이 비밀번호를 바꿔야(현재 것과 다른 값으로) 다른 API를 쓸 수 있습니다.

== 감사 로그

`/api/admin/**`의 변경 요청(POST/PUT/PATCH/DELETE)이 2xx로 끝나면 자동으로 한 줄 남습니다.
요청 본문은 저장하지 않으며, 상세가 필요하면 `requestId`로 앱 로그를 찾습니다. 로그인·재발급은 인증 전이라 남지 않습니다.

== 앱 API 요청 로그

앱 API(`/api/**`, 관리자 API 제외)의 모든 요청이 결과와 무관하게 한 줄씩 남습니다 — 비회원·인증 실패(401)도 회원 ID 없이 기록됩니다.
요청 본문·헤더·쿼리스트링은 저장하지 않으며, 상세는 `requestId`로 앱 로그를 찾습니다.
보관 기간(`admin.api-log.retention-days`, 기본 30일)이 지나면 매일 새벽 자동 삭제됩니다.
