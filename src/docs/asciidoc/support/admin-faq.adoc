=== 항목 등록

새 항목은 유형 내 마지막 순서로 들어갑니다. 수정은 `PUT /api/admin/faqs/{faqId}`에 같은 본문을 보내며,
`categoryId`를 바꾸면 그 유형의 마지막 순서로 옮겨집니다. 삭제는 `DELETE /api/admin/faqs/{faqId}`.

==== 에러

|===
| 코드 | HTTP | 설명

| `FAQ_CATEGORY_NOT_FOUND` | 404 | 유형 없음
| `FAQ_NOT_FOUND` | 404 | 항목 없음
| `FAQ_CATEGORY_NOT_EMPTY` | 409 | 항목이 남아 있는 유형 삭제
| `INVALID_REQUEST` | 400 | 순서 교체 ID 누락·중복
|===
