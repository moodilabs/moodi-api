== 1:1 문의 (Inquiry)

마이페이지 Support > Customer Service(`MY-06-01 ~ 06-03`)에서 사용합니다.
모든 요청에 `Authorization: Bearer {accessToken}` 헤더가 필요합니다.

문의는 `RECEIVED`(접수)로 등록되고 어드민이 답변하면 `ANSWERED`(답변완료)가 됩니다.

=== 첨부 업로드 흐름

서버는 파일 본문을 받지 않습니다. Pick 사진과 같은 방식입니다.

1. `GET /api/v1/inquiries/upload-url`로 파일 형식·크기를 보내 서명 URL과 `attachmentKey`를 받습니다.
2. 받은 `uploadUrl`로 파일을 직접 `PUT`합니다 (`Content-Type` 헤더는 1에서 보낸 값과 동일).
3. 문의 등록 요청의 `attachments`에 `attachmentKey`와 `contentType`을 순서대로 싣습니다.

첨부는 문의당 5개까지, 형식별 상한은 사진(JPG·PNG·HEIC)·PDF 10MB, 동영상(MP4·MOV) 50MB입니다.
스토리지가 준비되지 않은 환경에서는 `IMAGE_UPLOAD_UNAVAILABLE` 503입니다.

=== 문의 상세 조회

첨부의 `url`은 5분짜리 서명 URL이라 저장하지 말고 화면을 열 때마다 다시 조회합니다.

NOTE: 첨부의 읽기 URL 발급이 실패해도 **상세 조회는 200으로 성공**하며, 실패한 첨부만
`attachments` 에서 빠집니다. 예전에는 실패가 그대로 올라가 첨부 한 건 때문에 본문과 답변까지
읽을 수 없었습니다(스토리지가 준비되지 않은 환경에서 상세가 통째로 503). 따라서 클라이언트는
`attachments` 가 비어 있는 것을 정상 응답으로 다뤄야 합니다.
