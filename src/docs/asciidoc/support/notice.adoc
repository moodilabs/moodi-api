== 공지사항 (Notice)

마이페이지 Support > Notices(`MY-04-01`, `MY-04-02`)에서 사용합니다.
비회원도 진입하는 화면이므로 **로그인 없이** 조회할 수 있습니다.

공지는 어드민이 등록·수정·삭제하며, 앱에는 노출 상태인 공지만 내려갑니다.

=== 공지사항 목록 조회

등록일(`publishedAt`) 최신순, 같은 날짜면 ID 내림차순입니다.
커서는 `{publishedAt},{id}` 형식이며 응답의 `nextCursor`를 그대로 넘깁니다.

목록의 제목 앞 `[유형]` 표시는 `type`으로, 본문 2줄 미리보기는 `preview`로 그립니다.
