== 문의 관리

앱 `MY-06`에서 회원이 등록한 1:1 문의입니다. 답변하면 회원 화면에 `Answered`로 표시됩니다.
회원 정보는 문의 시점이 아닌 조회 시점 기준이며, 탈퇴 회원은 닉네임·이메일이 비어 있고 `withdrawn`이 `true`입니다.
