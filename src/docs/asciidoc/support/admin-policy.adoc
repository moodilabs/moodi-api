== 약관 관리

앱 화면 `MY-07`에 노출되는 약관입니다. 종류별로 버전을 쌓고, 앱에는 시행일이 지난 최신 버전만 보입니다.

[IMPORTANT]
====
시행일이 지난 버전은 **수정·삭제할 수 없습니다** (`POLICY_ALREADY_EFFECTIVE` 409).
회원이 동의한 시점의 문서가 보존돼야 하므로 오탈자 수정도 새 버전으로 등록합니다.
====

==== 에러

|===
| 코드 | HTTP | 설명

| `POLICY_NOT_FOUND` | 404 | 약관 없음
| `POLICY_VERSION_DUPLICATE` | 409 | 같은 종류에 같은 버전 존재
| `POLICY_ALREADY_EFFECTIVE` | 409 | 시행된 버전 수정·삭제
