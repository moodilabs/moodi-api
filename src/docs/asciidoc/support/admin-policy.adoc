== 약관 관리

앱 화면 `MY-07`에 노출되는 약관입니다. 종류별로 버전을 쌓고, 앱에는 시행일이 지난 최신 버전만 보입니다.

[IMPORTANT]
====
회원이 한 명이라도 동의한 버전은 **수정·삭제할 수 없습니다** (`POLICY_ALREADY_AGREED` 409). 시행됐더라도 아직 아무도 동의하지 않았다면 고칠 수 있습니다 — 목록·상세의 `agreed`로 판단합니다.
회원이 동의한 시점의 문서가 보존돼야 하므로 오탈자 수정도 새 버전으로 등록합니다.
====

==== 에러

|===
| 코드 | HTTP | 설명

| `POLICY_NOT_FOUND` | 404 | 약관 없음
| `POLICY_VERSION_DUPLICATE` | 409 | 같은 종류에 같은 버전 존재

|===

=== 국문·영문 및 공개 상태

`content`는 리치 에디터 HTML로 보냅니다. 서버가 jsoup 화이트리스트로 정제해 `p/br/strong/em/u/s/h1~h3/ul/ol/li/span[style=color]/a[href=http|https|mailto]` 외 태그·속성·스크립트를 제거합니다.

등록·수정 요청에 `locale` (`ko-KR` 또는 `en-US`), `enabled` (시행 활성), `visible` (공개 여부)를 지정합니다.
생략 시 기존 계약을 유지해 `en-US`, `true`, `true`를 사용합니다. 버전 중복은 `(type, version, locale)` 기준입니다.
`type`은 `TERMS_OF_SERVICE`, `PRIVACY_POLICY`, `MARKETING`이며, 기존 문서의 type 변경은 허용하지 않습니다.
앱에는 요청 언어의 `enabled=true AND visible=true AND effectiveAt <= 오늘` 중 최신 시행본만 표시됩니다.
공개를 중지하면 해당 버전을 제외한 이전 공개 시행본이 다시 조회될 수 있습니다.
회원이 동의한 문서는 숨김 또는 시행 중지 상태여도 본문·버전·언어·시행일 변경 및 삭제가 불가능합니다. 새 버전을 등록해야 합니다.
기존 버전은 관리자 목록·상세에 계속 남습니다. 상태 변경은 아래 API로 언제든 가능합니다.
