== FAQ

마이페이지 Support > FAQ(`MY-05-01`)에서 사용합니다.
비회원도 진입하는 화면이므로 **로그인 없이** 조회할 수 있습니다.

질문 유형(카테고리)과 항목은 어드민이 등록·수정하며, 유형 순서와 유형 내 항목 순서도 어드민이 정합니다.
앱에는 노출 상태인 유형 안의 노출 항목만 내려가고, 노출 항목이 없는 유형은 목록에서 빠집니다.
